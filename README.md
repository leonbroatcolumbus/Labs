# Agent in a Day — Columbus

Lab guides for Columbus's Agent in a Day workshop, adapted to the Vestbjerg
manufacturing scenario.

Live at: https://leonbroatcolumbus.github.io/Labs/

## What is here

| File | Lab |
|---|---|
| `lab1.html` | Build your first agent — Agent Builder, web-grounded |
| `lab2.html` | Give it what only you have — Copilot Studio, knowledge and tools |
| `lab3.html` | The first join in the chain — child agents and channels |

All images, stylesheets and scripts sit in the repository root alongside the
HTML, which is what the pages expect. Do not move them into a subfolder without
updating the references.
